# Changelog

All notable changes to SignBridge AI will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project
adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-07-25

### Added

- Project foundation and monorepo setup
- Turborepo configuration with pnpm workspaces
- Next.js web application with Tailwind CSS
- NestJS backend with Prisma ORM
- FastAPI AI service
- Flutter mobile application
- Shared packages (ui, types, config, eslint-config, tsconfig, api-client)
- Docker configuration for all services
- GitHub Actions CI pipeline
- GitHub issue and PR templates
- Husky, lint-staged, and commitlint configuration
- VS Code workspace configuration
- Documentation (Architecture, Setup, Development, Deployment)
