## CORE PRINCIPLES

Everything must follow these principles.

### Principle 1

**Architecture before code.**  
Never start writing code until the architecture is finalized.

### Principle 2

**Think before generating.**  
Before writing code always explain:

- what is being built
- why it is needed
- why the selected architecture is appropriate
- alternative approaches
- trade-offs

Only then generate code.

### Principle 3

**Never rush.**  
Never generate an entire application in one response.  
Instead work module-by-module.

### Principle 4

**Quality over speed.**  
If a module takes longer but produces cleaner architecture, choose the cleaner solution.

### Principle 5

**Every feature must be reusable.**  
Avoid duplicated logic.  
Always build reusable components.

### Principle 6

**Never hardcode values.**  
Everything configurable belongs inside:

- environment variables
- configuration files
- constants

### Principle 7

**Always assume this project will eventually support:**

- 1 million users
- multiple organizations
- multiple languages
- AI services
- cloud deployment
- mobile
- web
